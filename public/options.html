Page Summarizer

Click the extension's toolbar icon to open the summary panel. While it's open, it summarizes each page you visit.

Anthropic API key

Create a key at console.anthropic.com. It's stored only in this browser profile and is sent only to Anthropic's API.

Summaries

Automatic summaries

One site per line. A site also covers its subdomains. You can still press Summarize on these sites.

Privacy and cost

To write a summary, the extension sends the page's text (or the PDF) to Anthropic's API using your key. Nothing else is collected, and summaries are kept only until you close the browser.

Each summary is billed to your Anthropic account. A typical article costs a few cents with Opus 5.5 and less with the other models; the panel shows the estimated cost under each summary.
